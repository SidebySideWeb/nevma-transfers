Elite Protection · design kit

The office tool, in the house style

The admin (apps/admin) uses the same tokens as the public site: near-black, gold hairlines, ivory text, Playfair Display and Jost, square corners. The public site is spacious and photo-led; the admin is the same brand at work density. Staff use it for hours a day, so calm and legible beats decorative.

Rules

  • Type. Jost for everything you read and type: 15px body and table text, 13px meta. Playfair Display only for the wordmark, page titles (30px) and money totals. Labels are 11px tracked caps in the label gold. All numbers tabular.
  • Colour. Gold means "act here" (primary button, link, focus, current nav item, VIP flag). Status colours are for status only, always with a word. Red is for destructive actions and errors. No gradients except the sign-in background.
  • Shape and density. Square corners, 1px gold hairlines. Controls 40px high, table rows 44px (also the phone tap size). One primary button per area.
  • Tables first. Lists are tables with sticky headers, sorted server-side, grouped by Athens day where time matters. Below 720px a .table-cards table turns into stacked cards; every cell needs data-label.
  • Money and destructive actions always go through a dialog that restates reference, customer and amount; the confirm button names the action and the amount.
  • Feedback. Success is a toast (role="status"). Errors that need action stay on the page next to the field or as a red banner (role="alert"); never only a toast.
  • Banners on every page: DEMO data and Sanity mismatches (warning), "Prices changed: update the website" (info).
  • Motion. Colour changes only, 150ms. No slide-ins, no photo zoom. Reduced motion removes even those.
  • Accessibility. AA contrast on every pair, visible gold focus ring, keyboard reachable tables (role="region" tabindex="0"), labels on every input, status never by colour alone.
